# 凭证与网关

## 只读账户发现

默认只读发现：

- CCSwitch：`~/.cc-switch/cc-switch.db`
- magpie：`~/.config/magpie/providers.json`

只接受配置中平台端点明确为 `api.gaoxin.net.cn` 或 `api-sh.gaoxin.net.cn` 的 API 配置。选择前只返回名称、来源和稳定 ID；选定后才解析该项密钥。

不修改 CCSwitch/magpie 配置，不切换软件激活项，不读取 OAuth 登录文件，不读取全部密钥。数据库格式不兼容时报告不支持，不猜测凭证。

## 手动环境变量

没有可发现的账户时，可在 `~/.ziikoo-imagegen/config.json` 配置：

    {"key_env": "ZIIKOO_API_KEY"}

密钥放在环境变量 `ZIIKOO_API_KEY` 中，不写入任务、skill、项目、命令行或聊天。

## 本地网关

显式配置：

    {
      "key_env": "GATEWAY_KEY",
      "gateway_url": "http://127.0.0.1:实际端口/v1"
    }

网关须支持 `GET /v1/models` 和 `POST /v1/images/generations`；edit 须支持 multipart `/v1/images/edits`。配置网关后不直连平台，网关密钥不转发给直连端点。

CCSwitch、OpenCodex、magpie 可用于提供兼容地址或环境变量，但不能假设其图片接口、配置格式或当前激活账户可被本 skill 使用。

## 多来源

使用 `profiles` 映射可在无自动发现环境下手动登记多个来源。自动发现与手动映射可同时存在。选择 ID 必须稳定且不包含密钥。
