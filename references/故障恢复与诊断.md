# 故障恢复与诊断

先读取任务目录的 `record.json`：

    python scripts/client.py status --task <任务目录>

## 状态处理

| 状态 | 含义 | 下一步 |
|---|---|---|
| `success` | 图片已返回、保存并完整解码 | 查看并展示本次文件 |
| `artifact_failed` | 已收到响应，但保存或下载失败 | 只恢复已有响应，不重新生图 |
| `connection_not_established` | 连接未建立 | 仅在用户任务允许且有另一探测端点时切换 |
| `rejected` | 服务拒绝请求 | 显示脱敏错误；参数错误须修正或报告 |
| `result_unknown` | 结果和计费状态未知 | 停止，使用请求编号向客服查询，不重发 |

下载失败：

    python scripts/client.py resume --task <任务目录>

只重试原有响应中的图片 URL，不产生生图请求。不得把签名 URL 粘贴到聊天。

## 求助信息

本地 `record.json` 中查看具体错误。可以生成白名单报告：

    python scripts/client.py diagnose --task <任务目录>

报告排除提示词、账户名称、完整服务原文、request ID、模型 ID、密钥和签名 URL，避免误传客户信息。需要客服定位时，用户审阅本地错误后再手工补充 request ID。

向用户说明失败阶段、HTTP 状态、脱敏消息、错误码、来源、模型和端点。不得仅说“失败”或只给异常类型。
