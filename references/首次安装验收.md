# 首次安装验收

安装依赖和配置后执行，结果保存到用户状态目录，按客户端版本、配置名称和服务地址区分。新版本或服务配置变化后重新验收；不要写入 skill 安装目录影响自动更新。

安装初始化同时验证原生提问能力。先运行 `python scripts/ask_capability.py show`，传入当前 host、client、model、gateway、protocol、tool 和 version；untested 时发一次明确的 onboarding ask，让用户点击“原生选择可用”或“改用编号文本”。只有收到真实点击才可用 `record --status supported --evidence click_selected`；`unsupported call` 记录 unsupported；用户选择文本模式记录 text_fallback。该测试不调用图片接口、不产生生图费用，也不得自动代选。

## 无生图消耗阶段

1. 运行 scripts/offline_test.py：离线验证，不访问真实凭证、网络或模型。
2. 额度来源不明确时先 ask 选择，不自动测试其他账户。
3. 运行 python scripts/installation_test.py --profile 已选来源。每个端点 3 次串行 GET /models、2 次并发 GET /models；直连两个端点最多 10 次 GET，网关最多 5 次。没有图片生成 POST。通常不消耗生图额度，但实际计费由平台规则决定，不能用此测试证明账单为零。
4. 如实报告每个端点的状态和错误。GET 串并发通过只证明模型列表访问，不代表图片并发能力。

## 付费验收必须先 ask

先选择模型与额度来源。展示实际测试方案并等待明确同意：模型完整 ID、来源名称、图片将上传到所选服务、质量 low、1024x1024、计划请求次数上限、可能消耗额度且金额未知。不支持 low 时报告参数错误，修改参数后重新确认；不静默升级质量。用户拒绝时记录“付费生图与 edit 未验证”，仍可使用已验证的基础能力，不强迫付费测试。

提供可点击选择：“基础验收：最多 2 次 POST”“完整验收：最多 6 次 POST”“暂不进行付费测试”。无回答不能开始。次数包括失败请求；测试任务均设 no_fallback=true，禁止超出上限自动补测。网络结果未知即停止整个付费轮次，不再继续后续请求。支持情况变化或换模型/账户后重新确认。

- 基础验收：文生图 1 次，然后仅在实际图片成功保存后 edit 1 次。请求串行。文生图失败时不执行 edit，不用历史图片代替。
- 完整验收：2 次串行文生图、2 次并发文生图（并发 2）、1 次串行 edit、1 次串行 edit。总计最多 6 次 POST。并发阶段前已有未知结果则停止。并发中一个未知时等待另一个已发请求结束，不再启动新请求；不能撤销已经发出的请求。非 az/ 模型需明确说明限流风险。每个任务独立目录。普通生成仍保持串行，只有此项明确授权的测试允许并发 2。

调用 python scripts/client.py generate --job 任务.json；edit 使用 python scripts/client.py edit --job 任务.json，任务增加 image 为本轮真实生成图片绝对路径。edit 是 multipart /v1/images/edits。接口尚未经真实服务验证，不能把代码实现说成兼容性已确认。完整验收的并发通过只说明该次 2 请求成功，不代表账户最大并发。

## IMAGEGEN Logo 测试提示词

用户提供的极小参考图仅用于推导文字描述，不随包分发、不上传该原图。以下是设计方向近似，不是精确图形复刻。

文生图 prompt：

为 AI 技术品牌 IMAGEGEN 设计一个简洁、现代、易识别的品牌 Logo。画面中心只有一个横向英文标志，文字准确拼写为 IMAGEGEN，不添加其他文字。以几何无衬线字体构造字标，笔画清晰、紧凑且有适度留白，结合黑色、暖橙色与明黄色；将字母中的圆形结构处理得醒目，形成科技感与亲和力兼具的视觉节奏。纯白背景，平面矢量视觉，无渐变、无立体效果、无阴影、无样机场景、无水印。完整呈现标志，四周保留充足空白，适合网站页眉和应用品牌标识。

edit prompt（输入为本轮实际生成的 Logo）：

在输入 Logo 的基础上做小幅品牌精修。保持 IMAGEGEN 的正确拼写、横向布局、黑色与暖橙黄色主色及核心识别特征；统一笔画粗细，修正字母间距，改善圆形字母的对齐，使小尺寸更清晰。纯白背景、平面矢量视觉，不增加任何文字或装饰。输出完整 Logo 并保留留白。

验收：实际解码图片、检查尺寸和哈希、展示本轮图片；人工确认拼写、布局与 edit 是否生效。报告每次请求的实际状态、端点、模型（响应未提供则未知）、耗时、额度来源和脱敏错误，不推测账单。验收报告不包含密钥、签名 URL 或完整响应文件。
