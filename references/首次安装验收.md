# 首次安装与可选验收

安装成功以离线自检通过为准。不要求测试问卡、选择收费账户或生成 Logo。

## 最小检查

便携包运行 <client> self-test，检查运行时、配置格式与图片解码，零网络请求。源码在专属虚拟环境运行离线测试。首次真实任务复用 models 请求，不为初始化重复探测。

## 可选 GET 诊断

用户要求诊断时，在已明确来源上运行 python scripts/installation_test.py --profile <ID>：每端点一次 GET，无并发、无图片 POST。深入排错可增加 --full，每端点三次串行与两次并发 GET。记录保存在状态目录；GET 成功不证明生图接口、并发或账单。

## 可选付费验收

仅用户要求验收时提出方案：明确模型、来源、上传范围和请求上限。默认最多两次 POST（生成一次，成功保存后编辑一次）。失败计入次数，结果未知立即停止。批准后整轮沿用，不在 edit 前重复确认。测试可使用获准上传的图片或简单几何图形，无需固定品牌。

edit 默认 JSON images 结构，明确支持的服务才选择 multipart，见 [API调用](API调用.md)。报告实际结果、Content-Type、HTTP 状态、请求编号与本地图片验证；不得把离线回归当成真实网关已通过。
