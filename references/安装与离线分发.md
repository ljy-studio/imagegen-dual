# 安装与离线分发

## Windows x64 便携包

使用维护者发布的 imagegen-dual-<版本>-windows-x64.zip 与 SHA256SUMS.txt。包包含运行时及图片依赖，无需 Python、pip 或 Git，不改 PATH/注册表。此包不适用于 macOS/Linux。

GitHub 不可访问时，由维护者通过可信网盘、内网文件服务或直接传文件分发同版本包。当前未部署国内镜像，不内置未知下载代理。安装与自检可离线；实际生图仍需连接所选 API。

1. 从可信维护者渠道取得校验值，用 PowerShell Get-FileHash <包路径> -Algorithm SHA256 对照。同来源校验文件只能检查损坏，不能单独证明发布者身份。
2. 解压到新目录，顶层 imagegen-dual 内应有 SKILL.md、references、imagegen-dual.exe 和 THIRD_PARTY_LICENSES。
3. 检查宿主实际 skills 路径、同名安装与 AGENTS.md。只安装到空闲目标；同名但来源不同或有定制时保留原件，明确采用哪个版本，不同时启用两个同名副本。
4. 运行 ./imagegen-dual.exe self-test 和 ./imagegen-dual.exe install，不需要账户，不发送图片请求。
5. 日常使用 exe 的 profiles/models/generate/edit/status/diagnose/resume 命令。

升级通过验证新包、并排解压和自检后换包，保留旧版及 ~/.imagegen-dual 状态。不要后台执行未知新程序。未签名程序可能受企业策略限制，应审核或使用源码方案，不绕过终端限制。

## 已有 Python：源码方案

需要 Python 3.11+。在 skill 自己目录建立 .venv，不向用户项目或系统 Python 安装依赖。

Windows 执行 python -m venv .venv，再执行 ./.venv/Scripts/python.exe scripts/install.py。
macOS/Linux 执行 python3 -m venv .venv，再执行 ./.venv/bin/python scripts/install.py。

Git 克隆支持更新；可信源码 ZIP 初始化增加 --archive，无需 Git，但仍需要 Python 和依赖。源码 ZIP 不是免运行时包。离线依赖须提供对应平台 wheel 包或改用便携包，不自行选择公共 pip 镜像。

之后使用虚拟环境 Python 运行 scripts/cli.py。不自动安装系统 Python；无 Python 且非 Windows x64 时明确目前尚无对应免依赖包。

## 与现有环境共存

本 skill 只处理已选定 API 图片任务，不能改 AGENTS.md 提高优先级，也不能覆盖其他图片 skill。仅安装不改变已有路由，是否调用以用户意图及项目规则为准。
