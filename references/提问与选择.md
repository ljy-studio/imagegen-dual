# 提问与选择

## 原生 ask 能力

首次安装时，按 host、client、model、gateway、protocol、tool 和 version 查询 `scripts/ask_capability.py show`。

- `supported` 且工具仍在本回合工具列表中：直接使用原生 ask。
- `unsupported` 或 `text_fallback`：在编号文本选项中等待用户回复。
- `untested`：首次安装发一次 onboarding ask，让用户点击“原生选择可用”或“改用编号文本”。
- 非首次安装的新组合：默认使用编号文本，不在日常任务中插入测试问题。

`request_user_input` 和 `request_user_input_async` 是不同工具。Codex Default 模式优先检查 async；同步工具只在其允许的模式使用。Claude Code 使用实际暴露的 `AskUserQuestion`，DeepSeek Harness 使用其实际暴露的 `ask_user_question`。

工具返回 `accepted`、问题卡出现但无回复、用户关闭面板或等待超时，都不能视为用户已选择。只在收到真实答案后记录 `click_selected`。

## 首次安装 onboarding ask

问题应明确这是在验证交互方式，不调用图片接口：

- 原生选择可用
- 改用编号文本

原生 ask 返回 `unsupported call` 时记录：

    python scripts/ask_capability.py record ... --status unsupported --evidence unsupported_call

收到点击选项后记录：

    python scripts/ask_capability.py record ... --status supported --evidence click_selected

用户主动要求文本模式时记录 `text_fallback`。不得自动代选。

## 额度来源选择

运行 `python scripts/client.py profiles`。返回的是不包含密钥的来源名称和稳定 ID。

新对话未选来源时，即使用户只有一个配置也要显式选择。有原生 ask 时提供可点击选项；不可用时列出编号并等待回复。任何未回复都不构成选择。

选定后，任务中的 `profile` 填稳定 ID。切换来源但保留模型时，重新请求模型列表，确认原模型在来源中仍可用。

## 模型选择

选定来源后运行：

    python scripts/client.py models --profile <稳定ID>

只展示返回中与 `capabilities.json` 交集内的图片模型。选项使用完整模型 ID，保留 `az/` 前缀。模型不明确时按宿主容量分步询问，不预选默认值。

用户指定完整模型 ID 且实时列表中存在时可直接使用。模型下架、来源不匹配或精确模型缺失时停止并询问，不自动替换。

## 会话范围

用户直接指定或通过 ask 选定的模型和来源，在同一会话内持续沿用。上下文压缩后只能沿用当前会话交接信息；无法确认时重新询问。不得从其他对话、历史输出或全局配置推断选择。
