# 维护与发布

## 云端仓库

正式仓库：

    https://github.com/ljy-studio/imagegen-dual.git

稳定分支 `main`。`release.json` 固定可信仓库与分支，用户配置和凭证位于 `~/.imagegen-dual/`，不进入 Git。

## 自动更新

每次 skill 调用先运行：

    python scripts/update.py --auto

成功检查后 24 小时内不重复检查。无 Git、离线、工作树有修改、仓库不匹配或依赖文件变化时保留当前版本。只接受快进更新。

新版先在临时检出中运行离线测试和导入检查，通过后才合并。启用后启动检查失败且工作树干净时恢复旧提交。用户新增依赖须通过明确迁移步骤处理，不在后台自动升级。

## 发布流程

1. 更新 `version.json`。
2. 运行 `scripts/offline_test.py`、`scripts/release_test.py` 和 skill 格式校验。
3. 检查没有密钥、客户提示词、图片或用户配置进入仓库。
4. 提交并推送到 `main`。
5. 用全新目录克隆，执行 `scripts/install.py`，验证首次安装和每日更新。

不得把真实生图测试结果作为自动回归；付费测试须单独授权并限制次数。

## 回退

更新前旧提交记录在 `refs/imagegen-dual/previous`。回退前确认安装目录没有需保留的本地修改。不得覆盖用户状态目录、日志、验收结果和任务产物。
