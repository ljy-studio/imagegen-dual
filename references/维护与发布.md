# 维护与发布

源码 https://github.com/ljy-studio/imagegen-dual.git ，国内镜像 https://gitee.com/ljy-studio/imagegen-dual.git （release.json 的 mirrors），稳定分支 main。每次发布同时推送两处仓库与标签，并在两处 Release 上传相同便携包和 SHA256SUMS.txt。状态 ~/.imagegen-dual 不进入分发包。

## 更新

Git 源码按需运行 <client> update --auto，每安装目录一天至多一次自动联网检查，失败也退避。有本地修改、无 Git、离线时继续当前任务，不必逐次汇报更新。便携包及源码 ZIP 明确使用手动换包，不要求安装 Git。

源码更新先测试后快进，依赖变化暂停自动更新；不得用源码更新覆盖便携 exe。替换前核对来源及定制，保留旧版。

## 回归与构建

在独立构建环境依次运行 scripts/offline_test.py、scripts/grey_test.py、scripts/release_test.py；随后运行 scripts/package_release.py。

打包需要独立构建虚拟环境内的 requirements.txt 与 PyInstaller，不要求用户构建。只打包白名单代码、文档、配置与第三方许可证，输出 ZIP 及 SHA256 清单，当前目标 Windows x64。

更新 version.json，跑校验和无网络回归；在不含 Python/pip/Git 的 PATH 下解压便携包、自检与离线安装，再发布 prerelease。未实际验收接口时不声称全部兼容。包可通过 Gitee 镜像或可信文件渠道转发。真实生图测试另需授权。
